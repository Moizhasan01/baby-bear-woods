# Baby Bear's Woodland Tales

Create a professional multi-page children's author website for Nancy Jane Allen and her book "What's Eating Baby Bear? – Baby Bear's Adventures".

Use the provided book cover as the main visual inspiration. Match its warm woodland colors: forest green, sage, cream, golden yellow and natural brown.

Style: premium children's storybook, whimsical, cute cartoon/illustration feel, but still professional and clean. Use subtle leaves, flowers, trees and woodland elements with smooth animations.

Pages:

Home, About, Shop, Teachers, Parents, Contact.

Home should have a beautiful hero with the book, title, author name, "Shop the Book" CTA, featured book section, story/lesson section, author introduction, and Parents/Teachers cards.

Create a professional eCommerce-style Shop page with the book product and Add to Cart button.

Make the entire website responsive, modern, spacious and polished. Avoid generic templates, neon colors, excessive childish design, and stock-photo aesthetics. Make every page feel like the same magical woodland storybook brand.
